# 🏛️ Hachecko: Техническая архитектура, лицензирование и жизненный цикл продукта
## Архитектурная спецификация локальной агентной ОС подготовки досье (Karta Pobytu)

> **Версия:** 1.2.0-production  
> **Статус:** Актуальная архитектурная спецификация  
> **Архитектурный паттерн:** Local-First + Zero-Knowledge Pull-Only Cloud Rules + Antigravity Multimodal Agent Engine  
> **UX-принцип:** Глобальная карта готовности + строгий фокус «1 шаг = 1 действие»

## 📌 1. Архитектура доставки и распределения (Delivery & Distribution)

Для обеспечения 100% приватности (Local-First) и исключения серверных расходов на хранение и обработку чужих файлов архитектура разделена на два контура:

```
┌────────────────────────────────────────────────────────────────────────┐
│               Hachecko Cloud Server (Правила и Лицензии)               │
│  • Сервер авторизации лицензий (Stripe / LemonSqueezy API)            │
│  • Репозиторий версионированных модулей (JSON/WASM)                   │
│  • Актуальные налоговые пороги и регламенты воеводств («Living Law»)   │
└───────────────────────────────────┬────────────────────────────────────┘
                                    │ 
                                    │ 1. Запрос лицензии + Скачивание модулей
                                    │    (GET /api/v1/modules/sync?key=...)
                                    │ ❌ 0 байт данных клиента: НЕТ файлов, NIP, PESEL
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│                   Hachecko Local Engine (У юзера)                      │
│                                                                        │
│  [Кэш модулей в ОЗУ] ──► [Детерминированный FSM-контроллер]            │
│                                     │                                  │
│                                     ▼ (Пошаговые микро-сессии)         │
│                      [Antigravity Agent Runtime]                       │
│                      • Мультимодальное зрение (OCR не нужен)           │
│                      • Локальные файлы на жестком диске                │
└────────────────────────────────────────────────────────────────────────┘
```

### Форм-фактор поставки:
1. **Флагман:** **Tauri 2.0 Desktop App (`.exe` / `.dmg` / `.AppImage`)**
   * Вес дистрибутива: **~12–18 МБ**.
   * Frontend: Svelte / React + Tailwind (быстрый пошаговый визард).
   * Local Sidecar: легковесный локальный процесс, исполняющий Antigravity SDK (`google-antigravity`).
   * Прямой доступ к локальной файловой системе пользователя без песочниц браузера.
2. **Pro/CLI:** Скилл для Antigravity 2.0 (`agy skill install hachecko`) для технически подкованных пользователей.
3. *Примечание по PWA:* Браузерные PWA без нативного бэкенда исключены из-за невозможности прямого запуска агентного рантайма и изоляции песочницы.

## 🔒 2. Лицензирование, защита IP и принцип «Zero-Telemetry»

### 1. Модель доставки правил «Pull-Only» (Только скачивание)
* Приложение пользователя работает с сервером Hachecko **строго в одностороннем режиме**:
  * Клиент делает `GET /api/v1/modules/sync` с лицензионным ключом и хэшем железа (`Hardware ID`).
  * Сервер возвращает подписанный криптографический пакет актуальных правил.
* **Физический запрет на телеметрию:** В коде клиента отсутствуют сетевые эндпоинты, способные принимать или передавать тела документов, имена, PESEL, NIP, суммы транзакций или метаданные файлов.

### 2. Модульная структура скилла (Step-by-Step Modules)
Вместо монолитного промпта, который можно скопировать, логика разделена на микро-модули, подгружаемые пошагово в оперативную память:
* `mod_01_tree_blueprint.json` — матрица папок под тип семьи и основание подачи.
* `mod_02_classifier.json` — маркеры и семантика распознавания польских документов.
* `mod_03_reconciler.json` — налоговые формулы (минимальная зарплата $\times 12$, ZUS, PIT-28, сплит-платежи).
* `mod_04_delta_diff.json` — логика вычисления дельты для старых дел (>1 года ожидания).
* `mod_05_print_matrix.json` — правила тиража, описи (*Spis Treści*) и сборки готовых PDF.

### 3. Механизм «Живой закон» (Living Law)
* При изменении минимальной ставки в Польше (*Minimalne wynagrodzenie*) или бланков ZUS/Skarbówki администратор обновляет модуль на сервере.
* Все клиентские приложения получают актуальные формулы проверки при следующем запуске без необходимости переустановки `.exe`.

## 🛤️ 4. Пошаговый алгоритм работы от Этапа 0 (Zero State) до печати

### ЭТАП 0: Инициализация с нуля (В папке нет ни одного файла)

#### Шаг 0.1: Выбор рабочей директории
* Пользователь открывает приложение. На экране одна кнопка: **«Выбрать папку для досье на диске»** (например, `D:\Pobyt_2026`).
* Приложение связывается с локальной файловой системой.

#### Шаг 0.2: Экспресс-опросник (4 микро-вопроса Onboarding Wizard)
Визард задает вопросы по одному на экран:
1. **Экран 1:** «Кто подается на ВНЖ?»  
   *Кнопки:* `[Я один]` | `[Я + Супруг/а]` | `[Я + Семья с детьми ⭐️]` *(пользователь выбирает семью)*.
2. **Экран 2:** «Основание основного заявителя?»  
   *Кнопки:* `[JDG / B2B предприниматель ⭐️]` | `[Трудовой договор (Praca)]` | `[Blue Card]`.
3. **Экран 3:** «Состав семьи (Имена и возраст детей)?»  
   *Поля ввода:* Жена (Маргарита), Ребенок 1 (Екатерина, 7 лет — школа), Ребенок 2 (Марина, 4 года — детский сад).
4. **Экран 4:** «Форма налогообложения JDG?»  
   *Кнопки:* `[Ryczałt ⭐️]` | `[Podatek liniowy 19%]` | `[Skala ogólna]`.

#### Шаг 0.3: Мгновенная генерация полного чек-листа и дерева папок
На диске создается каноническая структура, а в левой панели UI **мгновенно появляется полный персональный чеклист**:
* **Михаил (12 пунктов):** B2B Контракт + присяжный перевод, CEIDG, Umowa najmu, Фактуры за год, Банковские выписки, Ewidencja приходов, PIT-28 + UPO, ZUS DRA (12 мес), ZUS ZUA, ZAS-W (<30 дн), ZUS RWN (<30 дн), ZUS ubezpieczenie.
* **Маргарита (4 пункта):** Копия паспорта, Свидетельство о браке (с присяжным переводом), Спонсорский пакет мужа (авто-копия), ZUS ZCNA.
* **Екатерина (2 пункта):** Свидетельство о рождении (+ перевод), Zaświadczenie ze szkoły (текущий учебный год).
* **Марина (2 пункта):** Свидетельство о рождении (+ перевод), Zaświadczenie z przedszkola.

### ЭТАП 1: Пошаговый сбор базовых документов («1 действие за раз»)

Центральная карточка начинает последовательно запрашивать файлы:

* **Микро-шаг 1: Контракт B2B.**  
  Центр: *«Перетяните ваш B2B-контракт с иностранным/польским заказчиком»*.  
  Юзер кидает `contract_en.pdf` $\rightarrow$ Antigravity видит английский язык $\rightarrow$ Карточка плавно меняется: *«Контракт на английском. Перетяните присяжный перевод (Tłumaczenie przysięgłe)»*.  
  Юзер кидает перевод $\rightarrow$ Чекбокс в левой панели загорается зеленым ✅ $\rightarrow$ Центр переходит к следующему шагу.

* **Микро-шаг 2: Выписка CEIDG.**  
  Центр: *«Перетяните выписку из реестра CEIDG»* (кнопка: *«Где скачать в 1 клик на prod.ceidg.gov.pl»*).  
  Юзер кидает $\rightarrow$ Файл переименовывается в `CEIDG_dane_niejawne_2026-08-24.pdf` и кладется в папку `mikhail/`. ✅

* **Микро-шаг 3: Договор аренды жилья (Umowa najmu).**  
  Юзер кидает `dogovor.pdf` $\rightarrow$ Antigravity считывает срок аренды и адрес $\rightarrow$ Софт **автоматически дублирует** этот документ в папки жены и обоих детей. ✅

### ЭТАП 2: Пакетная финансовая сверка (Фактуры ↔ Банк)

* **Микро-шаг 4: Сброс фактур и оплат скопом.**  
  Центр: *«Загрузите все фактуры и банковские выписки за последние 12 месяцев (можно скинуть сразу 30 файлов скопом)»*.  
  Юзер перетаскивает пачку файлов.  
* **Детерминированная работа алгоритма:**
  1. Софт автоматически группирует фактуры по месяцам: `Faktury/faktura-vat-01-MM-YYYY/`.
  2. Находит банковские проводки на ту же сумму и раскладывает по парам.
* **Разрешение неопределенностей (Строго 1 вопрос на экран):**  
  Если одна квитанция не сошлась с фактурой (например, клиент платил двумя частями через CA и Payoneer), на экране появляется **одна простая карточка**:  
  > *«Фактура № 06/2025 на сумму 14 000 PLN:*  
  > *Мы нашли оплату 10 000 PLN в Credit Agricole и 4 000 PLN в ZEN. Объединить их в один платеж?»*  
  > `[ ✅ Да, объединить ]`  |  `[ ❌ Нет, это другой платеж ]`

* **Сверка с реестром доходов:**  
  Юзер кидает `Ewidencja_przychodow.pdf` и `PIT-28.pdf` $\rightarrow$ Алгоритм проверяет: $\sum \text{Фактур} == \text{Ewidencja} == \text{PIT-28}$. В левой панели загорается статус: 🟢 **«Финансовый аудит сошелся на 100%»**.

### ЭТАП 3: Очередь внешних запросов (TODO Queue для справок <30 дней)

Справки `ZAS-W` и `ZUS RWN` имеют срок годности **30 дней**. Их нельзя заказывать за 3 месяца до подачи.

* **Микро-шаг 5: Контроль срока свежести.**  
  Центральная карточка: *«Документы собраны на 85%. Остались 2 справки с 30-дневным сроком годности»*.  
  1. Кнопка: **[ Заказать ZAS-W на podatki.gov.pl ]** *(открывает браузер на нужной странице)*.
  2. Кнопка: **[ Заказать RWN на pue.zus.pl ]**.
* Документы помещаются в левой панели в блок `⏳ Ожидание (TODO)`.
* Как только юзер скачивает готовые PDF из налоговой и перетаскивает их в окно — они мгновенно валидируются по дате и раскладываются во все 4 папки семьи.

### ЭТАП 4: Жизненный цикл через 1 год (Временная дельта / Отпечатки)

Прошел 1 год. Ужонд прислал вызов на отпечатки пальцев (*Wezwanie*).

1. Пользователь запускает Hachecko и нажимает кнопку: **«Актуализировать досье к визиту в ужонд»**.
2. **Алгоритм дельты (Delta Engine):**
   * Старые справки ZAS-W/RWN старше 30 дней автоматически переносятся в `archive/`.
   * Старые фактуры за прошлый цикл архивируются в `archive/Faktury_2024-2025/`.
3. **Фокусная карточка выдает только свежие задачи на визит:**
   * *«1. Перетяните свежий ZAS-W (не старше 30 дней)»*.
   * *«2. Перетяните справку из школы Екатерины на НОВЫЙ учебный год»*.
   * *«3. Скиньте фактуры и выписки за последние месяцы»*.
4. За 15 минут досье приведено в идеальное состояние на текущую дату.

## 💼 5. Дальнейшее масштабирование: Юридический отдел и саппорт

На базе структурированных данных Hachecko разворачивается высокомаржинальная экосистема услуг:
1. **«Urząd Watchdog» (Подписка на саппорт $15–$25/мес):** Трекинг статуса дела, мониторинг дедлайнов, шаблоны писем на ускорение (*Ponaglenie*).
2. **«Legal Pre-Check» (+$50–$80):** Экспресс-проверка досье лицензированным польским юристом (Radca Prawny) перед подачей.
3. **«Full Legal / Dispute» ($300–$1,000+):** Сопровождение апелляций (*Odwołanie*) и судебных исков (*Skarga do WSA na bezczynność*). Благодаря идеальной структуре папок Hachecko юрист тратит на дело 30 минут вместо 6 часов, что увеличивает пропускную способность юротдела в 5–10 раз.
